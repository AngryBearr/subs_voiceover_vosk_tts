# SH08 evidence archive snapshot — 2026-09-15

This is a local, lossless, snapshot-only archive of selected completed runs and
offline diagnosis evidence. It does not run inference, publish data, delete
sources, migrate storage, or claim semantic or audio truth. Each archive was
verified by streaming its tar members and by restoring them to a fresh
temporary directory for byte comparison; the temporary restore was removed
automatically.

unsafe names, and secret-looking names are refused.
